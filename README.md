# Project_Turret_AI
ตรวจจับและติดตามใบหน้า เพื่อใช้ในการรักษาความปลอดภัย (demo)

## 1. ขั้นตอนการรันระบบติดตามและจดจำใบหน้าอัตโนมัติ

### 1.1 เข้าไปยังโฟลเดอร์โปรเจกต์
เปิด Terminal แล้วพิมพ์คำสั่ง

```bash
cd /home/boomaie/Desktop/Project_Turret_AI
```

### 1.2 เปิดใช้งาน Virtual Environment
พิมพ์คำสั่ง

```bash
source venv/bin/activate
```

### 1.3 เริ่มการทำงานของระบบติดตามและจดจำใบหน้าอัตโนมัติ
พิมพ์คำสั่ง

```bash
python main_system.py
```

### 1.4 การทำงานของระบบ
เมื่อรันโปรแกรมแล้ว จะแสดงหน้าจอการทำงานของระบบติดตามและจดจำใบหน้าอัตโนมัติ โดยเริ่มต้นป้อมปืนจะหมุนค้นหาบุคคลรอบ ๆ ในแกน X ช่วงประมาณ 30 – 240 องศา
เมื่อระบบพบบุคคลที่อยู่ในฐานข้อมูล จะแสดงชื่อของบุคคลที่ตั้งไว้เป็นสีเขียว
เมื่อระบบพบบุคคลแปลกหน้า จะแสดงชื่อ `UNKNOWN` เป็นสีแดง และสั่งให้ส่งเสียงเตือนเมื่อพบบุคคลแปลกหน้านาน 10 วินาที จากนั้นเมื่อครบ 5 วินาที จะสั่งให้มอเตอร์เซอร์โวเหนี่ยวไกทำงาน

### 1.5 การปิดโปรแกรม
กดปุ่ม

```text
ESC
```

เพื่อปิดการทำงานของระบบ

---

## 2. ขั้นตอนการรันระบบสร้างฐานข้อมูลใบหน้า

### 2.1 ใช้ Terminal เดิม
หากยังอยู่ในโฟลเดอร์โปรเจกต์และเปิดใช้งาน venv แล้ว สามารถรันคำสั่งต่อไปได้ทันที

```bash
python face_train.py
```

หากยังไม่ได้เข้าโฟลเดอร์หรือยังไม่ได้เปิดใช้งาน venv ให้พิมพ์คำสั่งดังนี้ก่อน

```bash
cd /home/boomaie/Desktop/Project_Turret_AI
source venv/bin/activate
python face_train.py
```

### 2.2 กรอกชื่อฐานข้อมูลใบหน้า
ก่อนเริ่มต้นการทำงาน ระบบจะให้กรอกชื่อฐานข้อมูลใบหน้าของบุคคลที่จะบันทึก เช่น

```text
Enter person name : xxx
```

โดย `xxx` คือชื่อของบุคคลที่ต้องการบันทึกลงฐานข้อมูล

### 2.3 ปุ่มควบคุมการทำงาน
ในหน้าจอระบบบันทึกฐานข้อมูลใบหน้า จะมีปุ่มควบคุมการทำงานหลัก 2 ปุ่ม ดังนี้

1. `Space bar` ใช้เพื่อสั่งให้ระบบทำการบันทึกภาพใบหน้า
2. `Q` ใช้เพื่อหยุดการทำงานชั่วคราว
